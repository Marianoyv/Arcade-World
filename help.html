Common player questions

Open a question for the short version first. Each answer points to the next useful step.

Why do some game cards not launch immediately?

Arcade World mixes playable cabinets with catalog entries. Some games use an external provider; others need a local ROM because Arcade World does not bundle commercial game files. Check the play-mode label on the card before launching.

Check the Game Room
How do I play a ROM I already own?

Open the local player, select the system that matches the file, then choose the ROM from your device. NES, SNES, Game Boy, GBA, Genesis and MAME 2003 are currently listed. Arcade ZIP sets must match the MAME core they were built for.

Open local player
Does Arcade World upload or keep my ROM?

No. The selected file stays on your device and is used by the emulator inside that session. The library can remember basic metadata such as the filename and core, but it does not upload the ROM itself.

Read the privacy policy
Where can I get free games?

Start with creator-approved homebrew, demos, public-domain releases and games whose authors explicitly allow downloads. Arcade World links to official sources and does not mirror those files.

Open the download guide
Will my favorites and recent games be saved?

Yes, in the current browser or desktop app. They are stored locally, so clearing browser data or switching devices can remove them. Account sync is not active yet.

Open My Library
Are save states permanent?

Save support depends on the emulator core and browser storage. Browser data can be cleared by the user or operating system, so the desktop app is the better long-session path. Export or back up saves whenever the selected emulator supports it.

Learn about local play
Why does an external game show ads?

External providers control their own player, ads and availability. Arcade World cannot remove ads inside a third-party frame. For a clean session, use a creator-approved local file in Arcade World's own player.

Browse Freeplay
The game is slow, silent or does not respond. What should I try?

Reload once, click inside the player to give it focus, confirm the selected core matches the ROM, and close heavy tabs. On mobile, rotate to landscape. If a MAME ZIP fails, try the exact core required by that ROM set instead of renaming the file.

Report a persistent problem
Can I use a controller?

Most modern browsers expose standard USB and Bluetooth controllers through the Gamepad API. Connect the controller before loading the game, then check the emulator controls menu if buttons need mapping.

Read the controller guide
Is there an Arcade World desktop app?

The project includes a desktop build path for Windows, macOS and Linux. The web version already supports local imports; packaged downloads and automatic updates will be published after signed release builds are ready.
