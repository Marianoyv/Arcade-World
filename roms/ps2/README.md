# PlayStation 2 game images

Place only game images created from discs you own in this folder. Arcade World does not include or download commercial games.

Mercenaries 2 is configured at this exact path:

```text
roms/ps2/Mercenaries 2 - World in Flames.iso
```

If your legitimate dump has another filename, rename it to match or update `romPath` in `data/games-data.js`.

PCSX2's official disc-dumping guide explains how to create an ISO from your physical disc:

https://pcsx2.net/docs/setup/discs/

Large game files should remain local and must not be committed, deployed, or packaged for redistribution.
