# ROM files

Put only ROM files that you own or have permission to distribute in this folder.

Example catalog entry:

```js
{
    "id": "example-homebrew",
    "title": "Example Homebrew",
    "mode": "emulatorjs",
    "core": "nes",
    "rom": "/roms/example-homebrew.nes"
}
```

For arcade/MAME games, EmulatorJS expects the correct zipped ROM set for the selected core, for example `mame2003`.
